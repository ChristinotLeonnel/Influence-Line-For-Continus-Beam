# Steps:
# Numerical discretization step along the beam axis (m).
#
# This parameter defines the spatial increment used to divide each span
# into smaller segments for internal force and deflection calculations.
#
# The beam is evaluated at regular intervals:
#
#   x = 0, Step, 2×Step, 3×Step, ..., L
#
# Therefore:
#
#   Number of evaluation points per span ≈ SpanLength / Step
#
# ---------------------------------------------------------------------------
# ROLE IN THE ANALYSIS
# ---------------------------------------------------------------------------
#
# The step size directly influences:
#
# 1) Accuracy of results
#    - Smaller Step → More evaluation points
#    - Better resolution of shear, moment and deflection diagrams
#
# 2) Computational cost
#    - Smaller Step → More calculations
#    - Increased memory usage and execution time
#
# 3) Numerical smoothness of diagrams
#    - Large Step → Piecewise rough diagrams
#    - Small Step → Smooth curves
#
# ---------------------------------------------------------------------------
# RECOMMENDED VALUES
# ---------------------------------------------------------------------------
#
# Step = 1.0 m   → Fast preliminary design
# Step = 0.25 m  → Balanced precision (recommended)
# Step = 0.10 m  → High accuracy analysis
# Step < 0.05 m  → Research-level precision (slow computation)
#
# ---------------------------------------------------------------------------
# IMPORTANT NOTE
# ---------------------------------------------------------------------------
#
# Step does NOT modify:
#   - Structural stiffness (EI)
#   - Support reactions
#   - Exact analytical solution
#
# It only affects the numerical sampling resolution of the results.
#
# ---------------------------------------------------------------------------
# Example:
#
# For a span of 20 m:
#
#   Step = 1.0  → 20 evaluation points
#   Step = 0.25 → 80 evaluation points
#   Step = 0.10 → 200 evaluation points
#
